## Decision Tree 담당

```python
from sklearn.preprocessing import LabelEncoder
from sklearn.tree import DecisionTreeClassifier

# 범주형 Label Encoding
cat_cols = ['workclass', 'marital_status', 'occupation', 'relationship',
            'race', 'sex', 'native_country', 'occupation_group']

le_dict = {}
for col in cat_cols:
    le = LabelEncoder()
    X[col] = le.fit_transform(X[col])
    le_dict[col] = le  # test 변환용으로 보관

# 스케일링 X — Tree 모델은 불필요
# class_weight='balanced'로 불균형 처리
model = DecisionTreeClassifier(class_weight='balanced', random_state=42)
```

## 주의사항

1. **train에서 fit → test에는 transform만** (LabelEncoder, Scaler 등 전부)
2. **test에 없는 카테고리는 없음** 확인 완료 (걱정 X)
3. **prediction.csv 형식**: id, y_cls (0 or 1), y_prob (>50K 확률)
4. `na_values` 주의: CSV 읽을 때 `pd.read_csv('train.csv', na_values=['', ' '])` 권장
5. **Stratified K-Fold CV** 사용 권장 (75:25 불균형이라 일반 split은 불안정)

